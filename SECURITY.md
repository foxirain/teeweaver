# Security policy

## Supported versions

TEEWeaver is an alpha research tool. Only the latest tagged release is
maintained.

## Reporting a vulnerability in TEEWeaver

Do not open a public issue for a vulnerability in the framework itself. Use
GitHub's private vulnerability reporting feature for this repository when it
is available.

## Findings produced while using TEEWeaver

TEEWeaver elements are not vulnerability findings. Follow the affected
project's security policy and coordinated-disclosure process. Do not publish
candidate-specific traces, exploit details, or embargoed information through
this repository.

The maintainers cannot receive or coordinate reports on behalf of OP-TEE,
Trusted Firmware, Arm, or downstream vendors.
